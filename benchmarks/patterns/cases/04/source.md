# TB-04 Sandwich ELISA with Standard Curve

1. Use a clear 96-well ELISA plate.
2. Assign assay wells A1:H2.
3. Assign standard wells A1:H1.
4. Assign unknown sample wells A2 and B2.
5. Assign the positive control well C2.
6. Assign the negative control well D2.
7. Assign blank wells E2:H2.
8. Prepare an eight-point two-fold standard curve in reagent diluent at 2000 pg/mL, 1000 pg/mL, 500 pg/mL, 250 pg/mL, 125 pg/mL, 62.5 pg/mL, 31.25 pg/mL, and 0 pg/mL.
9. Assign the standards to A1:H1 in descending concentration order.
10. Add 100 uL capture antibody working solution to each assay well.
11. Seal the plate and incubate for 18 h at room temperature.
12. Aspirate liquid from each assay well without scratching the bottom of the well.
13. Wash each assay well 3 times with 400 uL wash buffer per wash. For each wash, fill the well with wash buffer, remove the wash buffer by aspiration, and retain the plate-bound capture antibody layer.
14. Add 300 uL blocking buffer to each assay well.
15. Seal the plate and incubate for 1 h at room temperature.
16. Aspirate blocking buffer from each assay well.
17. Wash each assay well 3 times with 400 uL wash buffer per wash.
18. Add 100 uL of each standard to its assigned standard well.
19. Add 100 uL unknown sample to each assigned unknown sample well.
20. Add 100 uL positive control to the positive control well.
21. Add 100 uL negative control to the negative control well.
22. Add 100 uL reagent diluent to each blank well.
23. Seal the plate and incubate for 2 h at room temperature.
24. Aspirate liquid from each assay well.
25. Wash each assay well 3 times with 400 uL wash buffer per wash.
26. Add 100 uL detection antibody working solution to each assay well.
27. Seal the plate and incubate for 2 h at room temperature.
28. Aspirate liquid from each assay well.
29. Wash each assay well 3 times with 400 uL wash buffer per wash.
30. Add 100 uL streptavidin-HRP working solution to each assay well.
31. Seal the plate and incubate for 20 min at room temperature protected from direct light.
32. Aspirate liquid from each assay well.
33. Wash each assay well 3 times with 400 uL wash buffer per wash.
34. Add 100 uL TMB substrate to each assay well.
35. Incubate the plate for 20 min at room temperature protected from direct light.
36. Add 50 uL stop solution to each assay well.
37. Gently tap the plate to mix the stopped color reaction.
38. Read absorbance immediately at 450 nm.
39. If wavelength correction is available, also read absorbance at 570 nm and subtract the 570 nm value from the 450 nm value.
40. Record blank-corrected absorbance values for the standard wells, unknown sample wells, positive control well, and negative control well.
41. Fit the standard wells with a four-parameter logistic curve.
42. Return the plate absorbance table, standard curve fit, and QC flags for blank, positive control, and negative control wells.
